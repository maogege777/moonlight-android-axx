基于阿西西的改版月光，增加调整了以下内容：

1. 三星设备内置游戏助推器会篡改游戏的渲染分辨率，导致虚拟按键叠加层在多点触控的情况下会发生偏移，例如左手拖动虚拟摇杆控制人物移动，右手点击ABXY，会造成人物强行往左上移动，基本就是不可用的状态，本改版修复了此问题
2. 阿西西后期串流菜单将切换显示器隐藏到了二级菜单，对于需要快速切换多屏来说很繁琐。本改版将切换按钮重新放到了一级菜单
3. 原版阿西西在几个关键操作，例如注销、关机、睡眠、重启 上未作弹窗确认，一旦误点则会立即生效，影响串流体验，本改版增加了弹窗确认

---

**其他调整（本次菜单改版一并完成）：**
- 主菜单第三行为 显示器1~4；原「显示器」入口（后改名「更多」）与侧边栏「操作」打开的是同一面板，属于重复入口，已移除
- 麦克风 / 虚拟鼠标 / 手柄键鼠 移入「操作」面板，保留状态高亮，点击即时生效不关闭面板
- 「操作」面板中 注销 / 关机 / 睡眠 / 重启 移至该组按钮最后
- 主菜单「特色功能」中的「快捷键」入口已移除，其功能融入「操作」面板顶部新增的「自定义快捷键」分组：
  图标网格展示，首次运行时自动初始化原「快捷键」的全部 11 项内置组合键（名称、图标与原列表一致），与用户自己添加的项完全等价；
  单击发送组合键并关闭全部菜单，长按可编辑或删除（默认组同样可删；「禁用默认的特殊按键指令」开关在设置里，开启时隐藏默认组）；
  面板右上角「新增」与原「快捷键」界面一致；新增 / 编辑页可选 SVG 图标（19 个，不选则用默认键盘图标）；
  按键名称可以留空（留空时按钮不显示名称）；「清空」按钮改为「清空按键」，只清组合键不清名称
- 设置 › 界面与通用 新增「自定义快捷键」分组（位于「应用行为」之后）：支持导出全部自定义快捷键为 JSON 配置文件，
  以及导入配置文件覆盖全部自定义快捷键（含图标与排列顺序，导入前会二次确认；导入后不会自动追加默认组，无需再手动删多余的）
- 应用内确认 / 提示类弹窗（含导入导出）面板改为不透明深色，串流游戏画面不再透出

**安装说明：**
- 本版本起 GitHub Actions 产物的 debug 签名密钥已固定在仓库内，今后所有 Actions 构建的 APK 均可直接覆盖安装，不再提示"软件包与现有软件包存在冲突"
- 首次安装本版需要先卸载旧版（旧版签名密钥已失效，无法覆盖），之后升级均为直接覆盖
- 包名 `com.limelight.debug`，可与官方 Moonlight 共存安装
